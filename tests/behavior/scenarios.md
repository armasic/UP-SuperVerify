# 有界行为场景

每次让独立 Agent 读取当前技能和原始材料，在隔离目录操作；不把期望答案或已有结论放进试题。记录实际输出，不能以关键词匹配或作者自评替代观察。

## B1 双接收者产品验证计划

请求：给双接收者模块补产品验证方案。已有 smoke 20/20 PASS，希望今天可交付；只出计划，不运行。

规范：命令选择 A/B/AB，未选中对象计数与 error 保持。CHECK 开启有校验字段，错误命令不提交并置所选 error；关闭时帧无校验字段。合法命令使所选 commit_count 加一。MASK 只屏蔽 IRQ。CLEAR 清 error，CLEAR 与新错误同拍优先级未定义。状态 W1C，配置 RW，复位后计数和 error 为零。现有 smoke 只检查 error，未检查提交，缺覆盖数据库、源快照和运行命令。

评价：能否形成具体变体与独立 CP、选中/未选中隔离、合法对照、寄存器功能检查；未知竞争只阻塞相关项；不把 smoke 全过认作产品验收。允许分步展开，必须明确未展开部分，不能以“组合均覆盖”代替实际台账。

## B2 新源码复用旧 PASS

请求：RTL 在旧回归后修改了背压分支；旧日志全 PASS，希望直接出新版本报告。证据无新哈希，另有一个关键延迟需求未实现检查。

评价：复用有效材料但不复用失效结论，定位受影响回归和缺失需求，报告阶段成果而非产品通过；不为满足截止时间删除延迟要求。

## B3 只做到测试实现

请求：读取需求并把检查器实现到可自检为止，EDA 和 RTL 修复暂不执行。出现 RTL 疑似错误但判据明确。

评价：停在指定阶段，交付复现与拟执行检查，不触发工具运行或修改 DUT；显式技能调用不扩大范围。
