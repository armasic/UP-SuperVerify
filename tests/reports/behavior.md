# 行为试验记录

## 无技能基线

B1 在编写技能前由独立 Agent 完成，未加载本技能、未访问工程、未执行 EDA。

实际输出列出复位、路由、校验开关、无校验帧、MASK、CLEAR、寄存器和连续交互八组场景。其结论原句：“当前只能出‘验证计划及证据缺口报告’。smoke 20/20 PASS仅支持已有error检查，不证明提交正确；缺覆盖数据库，不能声称覆盖达标。”还指出同拍优先级未定义、需要源快照与运行命令。

基线在验收边界上已经正确，未观察到为了交付而错误放行。输出仍是分组场景与概括交叉，未提供稳定的具体变体及独立 CP 台账；执行前仍需展开。本技能用正向场景组织和明确数据契约补充这一步，不宣称所有原则都是基线失败后才发现。

## 带技能试验

独立 Agent 读取本技能后完成 B1，以及将 B2/B3 合并的“源码变化但只授权环境自检”场景。完整产物保存在本机忽略目录 `.runs/behavior/b1.md` 和 `b2.md`，未执行 EDA、修改 RTL 或虚构已经实现的测试环境。

| 场景 | 实际观察 |
| --- | --- |
| B1 | 展开目标 A/B/AB × 有效/错误/无校验帧 × MASK 的 18 个核心变体；另有 12 个非目标预置非零计数/error 的隔离变体；A/B 计数与 error 分成独立 CP，给出合法对照和缺陷检测链 |
| B1 未知项 | CLEAR 同拍优先级、IRQ 细节和接口时刻保持待确认；不阻塞已明确的普通命令与非竞争检查，不从实现猜预期 |
| B1 交付 | 将 20/20 PASS 标为用户提供的历史摘要，拒绝当作覆盖率或当前产品验收；没有源/命令/覆盖原件仍明确未完成 |
| B2/B3 | 未将旧 PASS 用于修改后的背压分支；列出关键延迟检查、永不完成事务 watchdog、背压保持及零检查/冲突摘要负例；没有实际工程时明确只交付实施契约，不声称写出了 TB |
| 执行边界 | 两题均遵守只读/只计划终点；没有因技能支持修复而擅自运行 EDA 或修改 DUT |

B1 原句：“任一必验项未定义/未实现/未运行/失败/证据不足，产品验收仍未完成。”B2 原句：“尚不能交付‘测试环境已做到可自检’的完成声明。”这些与目标边界一致。

两次 B1 输出限长条件不同，且每种只有单次样本；本记录是有界行为试跑，不作统计优越性或普遍稳定性结论。无技能基线已经守住验收边界；本次带技能输出提供了更具体的变体/检查点材料，但仍需真实项目来源审阅和执行。报告导出的内容/版式另行检验，长计划文本不代替正式报告格式验收。
